# DayZ Sandbox

Herramienta de sandbox para crear escenas de cine/machinima en DayZ (Chernarus). Este repo recoge, por ahora, la documentación de producto y diseño; el código llegará más adelante.

- `product-spec.md` — especificación de producto.
- `research/` — investigación previa (herramientas, ecosistema DayZ, UI web, IA/MCP).
- `plans/` — planes del hito M1 (cine).
- `tickets/` — tickets de tools MCP necesarias.
