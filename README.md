# DayZ Sandbox

Herramienta de sandbox para crear escenas de cine/machinima en DayZ (Chernarus). Este repo recoge la documentación de producto y diseño y el código de la fase F0.

- `product-spec.md` — especificación de producto.
- `research/` — investigación previa (herramientas, ecosistema DayZ, UI web, IA/MCP).
- `plans/` — planes del hito M1 (cine).
- `tickets/` — tickets de tools MCP necesarias.
- `backlog-post-v1.md` — backlog tras el council post-v1.
- `DayZSandbox_dev/` — código: arnés `qa/` (m1_gate, bridge QA, peer falso), pruebas y evidencia. Pruebas: `python -m unittest discover -s qa/tests -t qa` desde esa carpeta (Python 3.14, solo stdlib).
